# 网络安全学习计划 - Web应用安全方向

## 📊 项目概述
- **目标**: 3个月内掌握Web应用安全基础知识，达到接单水平
- **基础**: 学过一些编程，但无网络安全经验
- **时间**: 每天1小时，共90小时
- **方向**: Web应用安全（网站漏洞挖掘）

## 🗓️ 3个月学习计划大纲

### 第1个月：基础建设期（30小时）
**目标**: 掌握Web安全所需的基础知识和技术栈

#### 第1-2周：网络与Web基础
1. HTTP协议深入理解（请求/响应、方法、状态码、Cookie/Session）
2. Web应用架构（前端/后端、数据库交互）
3. 浏览器开发者工具使用
4. Linux基础命令和操作

#### 第3-4周：编程技能强化
1. Python基础（用于编写自动化脚本）
2. SQL语言基础（理解数据库操作）
3. JavaScript基础（理解前端安全）
4. 常见Web开发框架了解

### 第2个月：核心技术期（30小时）
**目标**: 掌握Web安全核心漏洞和工具使用

#### 第1-2周：OWASP Top 10漏洞原理
1. SQL注入（原理、类型、检测方法）
2. 跨站脚本（XSS）（反射型、存储型、DOM型）
3. 跨站请求伪造（CSRF）
4. 文件上传漏洞
5. 命令注入

#### 第3-4周：安全工具和实践
1. Burp Suite基础使用
2. SQLMap工具使用
3. Nmap网络扫描
4. 漏洞扫描器基础
5. 手动漏洞测试方法

### 第3个月：实战提升期（30小时）
**目标**: 实战能力提升和接单准备

#### 第1-2周：靶场实战训练
1. DVWA（Damn Vulnerable Web Application）
2. WebGoat
3. PortSwigger Web Security Academy
4. HackTheBox基础挑战

#### 第3-4周：接单能力建设
1. 漏洞报告编写规范
2. 安全测试方法论
3. 接单平台了解（如：漏洞盒子、补天、CNVD等）
4. 法律和道德规范学习

## 📋 详细知识要点

### 1. 网络基础模块
- TCP/IP协议栈基础
- HTTP/HTTPS协议详细
- DNS工作原理
- Web服务器架构（Apache/Nginx）

### 2. Web技术模块
- HTML/CSS/JavaScript基础
- Cookie、Session、Token机制
- 同源策略和CORS
- 前端框架安全考虑（Vue/React）

### 3. 漏洞知识模块
- OWASP Top 10 2021版所有漏洞
- 业务逻辑漏洞
- 信息泄露漏洞
- 权限绕过漏洞
- 第三方组件漏洞

### 4. 工具技能模块
- Burp Suite（Proxy、Repeater、Intruder、Scanner）
- SQLMap（自动化SQL注入检测）
- Nmap（主机发现、端口扫描、服务识别）
- dirsearch/dirb（目录扫描）
- Wfuzz（参数模糊测试）

### 5. 实战能力模块
- 漏洞挖掘方法论
- 漏洞验证和复现
- 漏洞报告编写（格式、内容、截图）
- 修复建议提供

## 🎯 3个月目标里程碑

- **第1个月结束**: 能理解常见漏洞原理，搭建测试环境
- **第2个月结束**: 能在DVWA中成功利用所有基础漏洞
- **第3个月结束**: 能在授权网站上发现1-2个真实漏洞并提交报告
